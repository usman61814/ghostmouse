# GhostMouse

A Windows app that keeps the computer active by moving the mouse like a real person.

## What it does
- Moves the mouse naturally: curved paths, changing speed, random pauses, small overshoots and tiny hand shake.
- Records custom mouse paths and replays them.
- Presses chosen keys automatically at set intervals.
- Stops when I touch the mouse, so it never gets in the way.
- Runs from the system tray with a simple settings window.
